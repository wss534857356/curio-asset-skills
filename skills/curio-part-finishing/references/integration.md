# 连续加工玩法接入

本页提供实现指导，不是可直接安装的雕刻游戏。沿用目标项目的工件 ID、剧情入口、材料商城与存档层。

| 模块 | 适配内容 |
|---|---|
| 工位与输入 | 支撑、稳定镜头、工具拾取、夹具局部连续轨迹 |
| 几何与蓝图 | 材料场、目标轮廓、厚度、过切与不可加工区域 |
| 任务状态 | 独立 attempt、合格／报废、标准件替换、待安装 |
| 材料与经济 | SKU、预留、首次去料耗用、购买和库存 |
| 装配与试用 | 对位、紧固、完整取放路径、最后功能检查 |
| 存档 | 幂等购买／耗料、材料场、夹具姿态、失败与安装状态 |

旧玩法如果只累计区域次数，改成拖动采样仍不是连续加工。判定来自剩余材料与关键结构；静止或点击不去料，故意越线能报废。保留已完成存档，中途数据迁移明确记录，不能凭空归零或赠料。

## 眠鹿圣油壶颈圈示例

[D02 设计数据](../assets/d02-collar-plan.example.json) 描述两半颈圈遗失后分别加工、换标准件与手动复装的方案。本集合仅展示模型整件／拆件渲染，不分发该 GLB，也没有附带可执行加工系统。

节点角色是壶身、盖、柄和两半颈圈。示例 ID 为 D02_body、D02_lid、D02_handle、D02_collar_px、D02_collar_nx；使用自己的模型时替换这些 ID 与来源清单。

源模型为零间隙分件检查版，单位未做物理标定，保留部分源模型缺陷。分解图不能证明取放路径或紧固件已验证。两半颈圈应分别从真实节点派生，不能盲目镜像；只处理缺件所需接口，不重做整个壶。

## 验收

分别实际验证正常磨、越线失败、付费换坯、合格换模、手动复装与保存恢复。标准件作者自身穿模应修正接口，不能让合格玩家重买材料。示例价格和阈值不是目标游戏的既定经济规则。

只完成方案时如实报告；实际工位操作通过后才报告完整玩法接入。
