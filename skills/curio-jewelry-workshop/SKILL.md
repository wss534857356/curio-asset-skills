# 珠宝、钻石切型与玉牌制作

把宝石本体、背面和镶座作为同一件可翻看藏品设计。正面好看只是其中一项：背部轮廓、厚度、承托接触和拆开后的画面也要成立。

## 识别本次范围

- 用户只问背面方案、设计规则或创建 skill 时，交付相应设计与文件，不自动生成图片、重做模型或改游戏。
- 用户要求制作或替换时，沿用已有身份、物种纹样、尺寸约束、物品 ID 和玩法接口，做到所要求的实际接入；不要停在概念图。
- 先读当前原画、模型截面、材质和真实加载路径。已有可用参照就复用；新增外观图用当前可用的 ImageGen，先查看本地参考并记录提示词与选用文件。几何本身用代码或建模工具制作。
- 在目标项目接入时，读取 [项目接入说明](references/integration.md)。不要仅凭旧截图、旧面数或登记状态认定当前模型。

## 按切型选择正背面

先看截面和用途，不能只凭“椭圆”就判断背面：椭圆蛋面和椭圆切面宝石属于不同结构。

| 类型 | 正面 | 背面与闭合方法 |
|---|---|---|
| 椭圆／水滴蛋面 | 连续凸曲面 | 优先评估独立浅拱背，前后曲面经腰棱连接；需要平稳承托或款式要求时，可用小平台背／平底 |
| 切面宝石 | 台面、冠部和有明确法线边界的切面 | 按亭部切面收向底尖或底面，保留真实厚度；不套用蛋面的光滑背拱 |
| 玉牌／薄片吊坠 | 以平面轮廓为基础，可加浅浮雕 | 平背或微拱背，挤出实体厚度并倒角；可翻看的藏品不能只靠一张双面着色平面 |
| 珠子 | 连续封闭圆体或异形体 | 按需要建立穿孔、孔壁和孔口圆角；不强行增加腰棱或镶座 |

椭圆蛋面的起始方案是“前高、后浅”，两侧可以复用同一曲线族，但拱高和控制点独立。背拱深度可先试前拱高度的 15%～35%，再按图和镶座空间调整；这是美术起点，不是所有天然宝石的切磨标准。具体连接、厚度和法线规则见 [正背面与镶座](references/back-surfaces.md)。

## 把设计落实为几何

钻石和异形裸石的切面排布、平面求交、心形凹口及实际面数统计，按需读 [切面结构](references/faceted-cuts.md)。贝塞尔曲线可以约束外轮廓，光学切面本身保持平面。

先记录足以指导本次建模的参数：轮廓、长宽、前拱、背型／背拱、腰棱厚度、最薄处、孔位、倒角、承托区域、拆件路径及目标视角。[设计例子](assets/design-examples.json) 提供双曲面蛋面和玉牌的参数组织；它是设计模板，不是现有项目已实现的接口。

- 蛋面：独立前后贝塞尔截面，经旋转或椭圆环采样形成闭合网格。曲率／弦误差大处增加采样，平缓处减少；腰棱共享位置，尖点只保留一个有效极点。
- 玉牌：轮廓填面、挤出厚度、建立侧壁及孔壁，再做边缘倒角。正背面可以是平面，整件仍要有体积。
- 切面：先确定切面排布和角度，再分配网格；保留切面间的硬法线，小倒角仅用于边缘受光。增加同一平面内的三角形不会增加切割层次。
- 浅纹、磨砂与细微材质颗粒可用贴图或法线；改变剪影的雕刻、穿孔、深凹槽和断口需要几何。
- 简单宝石、包边、爪座优先用参数化代码／Blender 曲线。复杂独立雕塑装饰才考虑外部网格生成，并遵循对应工具的当前授权和预算规则。

## 镶座与拆装

镶座必须由最终石体截面确定承托位置，不是一个统一圆环套在所有宝石下面。

- 将石体、腰棱承托、活动爪、底盖／背衬等按实际作用分开。裸石或一体玉牌没有这些部件时，不额外添加。
- 背拱向内占用的空间需要真实留空；承托环落在可承重区域，避免中央背拱悬在不合适的平板上，或底尖穿过镶座。
- 爪尖的位置跟随正面曲率；修改背面或厚度后重新检查接触、离隙、重心和落座高度。
- 需要拆装时先释放固定件，再沿安全方向提起，最后分离；复装按相反顺序。转轴放在实际铰接处，连接在同一爪上的尖端随其一起运动。
- 欺骗性底箔、涂线背衬或夹层按已有剧情独立建模；不能为美术方便把它们并入真品石体，也不自行新增赝品结论、奖励或磨损系统。

## 材质与游戏效果

处理通透、塑料感、陈列烘焙、拿放过渡或首次卡顿时，读 [透射与陈列](references/transmission-and-display.md)。先把几何、真实后景、反射和离屏渲染的成本分开定位。

- 把网格厚度、透射、折射率和颜色衰减一起考虑；Alpha 降低不能代替宝石透射。玉石、玻璃、金属和不透明矿石分别调材质，不统一做成水晶。
- 猫眼／星光等特殊效果若是美术近似，应随所宣称的光向或视角改变；固定画线留给贴图或已有赝品表现，不称为物性模拟。
- 反面可按工艺设为抛光、稍粗糙或带承托平台，不机械复制正面花纹和高光。先保证结构，再决定是否需要额外纹理。
- 大块反光也可能来自环境图或光照分档。用灰模、线框和单灯对照区分反射、法线与真实轮廓问题，避免只靠加面补材质问题。
- 复用项目材质和反射资源。近看与陈列可用不同采样密度，但腰棱、厚度、孔位、接口和原点必须一致；预算以实际三角形数和目标机位为准。

## 验收与交付

设计阶段说明选用的背型、理由和截面关系；制作阶段再检查实际产物。

- 查看正面、背面、侧面和拆座后的石体；确认背面是所选曲面或平面实体，没有用另一片相交网格遮住旧封盖。
- 检查曲面闭合、法线朝向、零面积面、最小厚度、孔壁，以及固定件的接触和运动路径；平滑法线不能替代圆滑的外轮廓。
- 在实际游戏光照与可用检视缩放下检查轮廓和材质，尤其是反面、背衬、近距离边缘和手机操作。保留旧图及不影响玩家存档的对照方法。
- 只运行与变动风险有关的检查和项目要求的构建。报告实际修改的资产、源文件、规格、运行路径、检查结果及材质近似；区分已实现的模型和待实现的设计字段。
