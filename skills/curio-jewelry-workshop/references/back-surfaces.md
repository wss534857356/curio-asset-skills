# 正背面与镶座

在选择背型、构建网格或调整已有宝石的背面时读本页。以下约定为建模方法和美术参数，不作真实加工认证。

## 1. 椭圆蛋面：两条独立截面

一件完整石体由前曲面、腰棱和后曲面闭合。背部浅拱可以让翻面时有连续体积，也为镶座提供可以明确设计的承托区域。

建议用以下可独立调整的量：

- `outline`：腰棱平面内的椭圆、梨形或自由轮廓。
- `front_rise`、`back_rise`：相对各自腰棱边界的前后拱高。
- `girdle_thickness`：腰棱上下两圈之间的距离。
- `back_style`：浅拱、带小平台的浅拱或平底。
- `minimum_thickness`：检查整件石体，不只看中轴处。
- `support_band`：承托带的位置与宽度，不与石体材质背衬混为一件。

不要直接复制正面深度到背面。对当前 C12 类型，可先以背拱约为前拱 1/5～1/3 试形，再用侧视和镶座空间决定。

### 可移植的坐标表达

令腰棱中面为 `Y=0`，短轴沿 X、长轴沿 Z，`rx/rz` 为半轴。每条贝塞尔截面输出归一化半径 `r(t)` 和高度 `h(t)`，从中心 `r=0` 到外缘 `r=1`：

```text
x = rx * r(t) * cos(theta)
z = rz * r(t) * sin(theta)
front_y = +girdle_thickness / 2 + front_rise * h_front(t)
back_y  = -girdle_thickness / 2 - back_rise  * h_back(t)
```

前后可以使用同一类曲线，但控制点和拱高独立。中心附近取水平切线形成圆润极点；腰棱附近按需要过渡到竖直切线或明确的倒角。腰棱边界的位置对应，而不是把两个曲面拉到同一高度。

一个起始例子，控制点坐标为 `[归一化半径, 归一化高度]`：

```text
front: [[0,1], [0.55,1], [1,0.58], [1,0]]
back:  [[0,1], [0.60,1], [1,0.36], [1,0]]
```

背面在上式中使用负高度方向。把两个曲面与腰棱连成一层封闭外壳；如果旧模型已有平底封盖，应替换对应封盖，而非在其外面再叠一个凸面。

前后自适应采样数量可以不同，各自连接到同一分段规则的腰棱环。曲线形状不同意味着同一 `t` 未必是同一半径：检查厚度时比较同一实际投影位置的前后高度，不能直接比较同一下标的采样点。

镜像复用网格时要同时核对三角形绕序、法线与 UV；双面着色不能证明背面朝向和壳体闭合正确。

### 承托方式

- **浅拱背＋环形托口**：托口贴近腰棱内侧可承托的带状区域，中央留出背拱空间。适合开底镶座和翻面检查。
- **浅拱背＋小平台**：保留平滑背部主体，在实际承托处做小平台；平台边缘圆滑过渡，避免整块背面像被随意截断。
- **平底＋托口／托板**：当图稿或结构需要平底时可直接采用，边缘有真实厚度和合适的小倒角。

先从背面轮廓求出接触位置，再定托口高度。任何试作间隙都应按模型尺度记录，不把屏幕上看不见的穿插算作装配合格。

## 2. 玉牌：平面是基础，厚度是实体

用闭合二维轮廓确定正面及孔位，填面后挤出厚度，生成背面、外侧壁和孔壁。正面和背面可以都保持平直，也可以只给一侧极浅起伏。

- 大平面不必密铺三角形；圆角、弯曲轮廓、孔口和实际浮雕处才需要增加几何。
- 倒角宽度要适应板厚及孔边余量，不能让窄边或挂绳孔附近自交。
- 挂绳孔和透雕是真实通孔；有前后视差的结构不用透明贴图伪装。
- 花纹、细刻线或打磨痕可走法线／高度图；深刻、明显浮雕及改变剪影的部分用几何。
- 正背面纹样分别定方向。背面有文字时独立核对阅读方向，避免把正面 UV 直接镜像过去。
- 单张平面适合只看正面的图标或远景卡片；能在手中转动的玉牌采用有厚度的模型。

## 3. 切面宝石：背面属于切割结构

从腰棱向底尖／底面组织亭部切面，和冠部、台面共同定义体积。面间保持明确法线边界；小倒角只软化边缘受光，不能抹掉所有切面。

不要把所有椭圆轮廓都归为蛋面，也不要用一个平底盖替代本来应该能翻看亭部的切面石。亭部深度和镶座高度配合，底尖不能穿进托板。

## 4. 正背面共同检查

| 检查 | 关注的问题 |
|---|---|
| 正面／背面／侧面灰模 | 前后拱高、平台、板厚和腰棱是否真实存在 |
| 裸石与装配对照 | 背拱／底尖与底座间是否有空间，接触带是否成立 |
| 单灯与转动 | 平滑轮廓是否被错法线、硬反射卡片或光照分档误显成分面 |
| 拆装中间姿态 | 固定件先解除，石体再离座；中途没有穿过仍闭合的爪 |
| 完整外壳 | 无多余内封盖、零面积三角形、破洞或翻面消失 |
| 低模 | 大轮廓、厚度、承托、孔位和底尖位置保持一致 |

## 5. C12 本轮建议

保留当前前拱与腰棱投影，新增一条独立浅背曲线。先利用开底银座的内部空间，再重新计算内托口和赝品背衬的位置。让玩家翻面时能读出浅拱、承托带和独立背衬的层次。

这是一项设计建议。当前模型是否已经实现，应以源码和实际反面截图为准，不能仅因这份规范存在就报告 C12 已改为双曲面。
