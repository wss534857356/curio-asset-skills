# 珠宝接入目标项目

本技能提供设计规则与参数示例，不附带原游戏构造器、GLB 或存档。先定位目标项目的模型工厂、藏品登记、材质、检视控制与资源释放入口，再映射这些职责。

## 稳定接口

- 保留藏品 ID、真伪状态、支撑面、原点和安装矩阵。建模与引擎单位明确转换，不把示例控制点直接当毫米。
- 石体、活动爪、承托和背衬按功能分件。操作绑定稳定节点或控制器，替换网格后核对拾取。
- 近看与陈列可用不同采样密度，但轮廓、厚度、腰棱和安装位置一致。分别测量石体与整件的三角形数。
- 查看和拆座只改变展示状态；库存、银币、剧情与真伪交给游戏现有状态层。
- 异步加载、错误回退、共享材质与释放沿用目标引擎约定。

## 展示案例的真实边界

图库里的 C12 山猫眼石由程序几何制作，截图版本为**前贝塞尔拱面、平底封盖、腰棱过渡与可分离银座**。前高后浅的双曲面背部是本技能指导的新设计，并非截图版本已实现的功能。

该版本近看石体为 2,880 个三角形、整件真品为 8,792；陈列整件为 3,188。这些是案例预算。猫眼亮带随主光与视角变化，属于游戏美术近似，不是完整宝石光学。

## 修改背面

1. 确定背型、厚度与腰棱关系，保留有效轮廓和接口。
2. 替换旧封盖并重建背部，避免叠一片相交壳体伪装背拱。
3. 调整承托、爪尖与背衬，检查松爪、提起、分离和复装的中间姿态。
4. 查看真伪版本及各细节等级的正、背、侧面，检查闭合、法线、零面积面、最薄处和装配空间。
5. 在隔离工作台验证真实灯光、缩放与交互，不修改玩家存档。

需要机械盒体时配合 `curio-mechanism-workshop`；需要玩家连续去料与报废时配合 `curio-part-finishing`。概念图不能代替几何与运行时验证。
