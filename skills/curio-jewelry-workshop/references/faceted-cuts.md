# 切面钻石与异形裸石

在制作切面宝石、增加切割层次、处理尖端或凹口时读取。蛋面与玉牌的连续曲面规则仍见主技能和正背面说明。

## 先分清轮廓和切面排布

圆形、椭圆、梨形、马眼、心形和枕形首先描述轮廓；同一轮廓可以使用不同的冠部、亭部切割方式。不要把“椭圆”直接等同于光滑蛋面，也不要给所有轮廓套一套等比例缩放的圆钻网格。

| 排布 | 建模关注点 |
| --- | --- |
| 明亮式及其异形变体 | 台面、主冠面、星面、腰棱上下切面与亭部的交接 |
| 阶梯式 | 平行轮廓逐层收束，明确背部收成短脊还是小底面 |
| 混合式 | 分别设计冠部与亭部，交界处仍要闭合 |
| 玫瑰式 | 三角冠面形成拱顶，背面可以是实体平底；不强加深亭部 |

分类参照 [GIA 切割方式图解](https://www.gia.edu/gia-news-research-value-factors-gem-cutting-styles-definitions)。这里只借助结构分类设计原创游戏网格，不复制参考图或宣称切工评级。

## 贝塞尔曲线用在哪里

贝塞尔曲线适合定义梨形肩部、马眼尖端过渡、心形双肩等**外轮廓**，也适合蛋面的连续截面。切面本身应保留平面性：

1. 先定台面、腰棱、冠高、亭深及底部收束形式。
2. 为主要光学面定义平面；通过平面相交或约束交点生成顶点。
3. 在各光学面自己的二维平面中三角化，让同一面内的三角形共享同一法线。
4. 在切面边界拆法线，在几何边界保持位置闭合。

同一平面上增加三角形不会产生新的闪光层次；给所有顶点平滑法线则会把切面变成鼓起的塑料面。先检查平面、边线和材质，再决定是否加几何。

## 异形中容易出错的部位

- **心形凹口**：保留非凸边界，在局部平面做凹多边形三角化。全局凸包会填掉凹口，中心扇形补面也可能跨过凹口。
- **马眼与公主方**：尖端、方台面和多层 V 形亭部需要独立约束。只有目标本来为凸形时，才用凸包选取朝外的支撑面；不能将凸包当所有切型的修复器。
- **阶梯底部**：短脊、小底面与底尖是不同设计。不要为了统一生成器而强行合成一个极点。
- **玫瑰式**：平底也需要厚度、侧壁和闭合边，不是一张双面着色平面。
- **细棱抛光**：若使用材质法线近似，计算到有限线段的距离，并夹紧投影参数；使用无限直线会让凹口边线影响台面中央。抛光层不能改变主切面的折射方向或冒充几何倒角。

## 尺寸、统计与检查

明确前轴、腰棱平面、单位和安装比例。预览中两单位高的裸石，不等于两毫米。落在布面或承托上时，应按实际接触面和局部高度确认离隙，避免只把包围盒底点放到桌面上。

分别记录：

- 设计光学面数，是否含腰棱和底面；
- 实际三角形数，以及实例数量；
- 资产文件大小、纹理与运行时渲染目标的内存预算。

检查平面性、零面积面、共享边绕向、正体积和法线。硬边非索引网格会复制顶点；闭合检查应在合理公差内按位置建立拓扑，不能把每个拆开的法线顶点误判成孔洞。对非凸轮廓，不只凭“法线背离某个中心点”判断所有面是否朝外。

新增切型或导出器时，重新加载**实际导出的文件**检查正、背、侧视图、尺寸和材质回退。GLB 里的基础材质与网页的自定义着色、环境采集、辉光要分别说明。
