# 器形还原与美术验收

在制作藏品外观或用户指出“像积木、全是方盒、只有贴图变精细”时读本页。精密机构与美术形体同时成立；低面数和代码建模也可以有成熟的工业／手工造型。

## 概念图要落实到什么

先查看实际选中图，在工件规格中简短记录可见特征及实现位置。没有必要为已清楚的设计重复生图。

| 层次 | 观察与制作 |
| --- | --- |
| 主轮廓 | 长宽高、圆／椭圆／多边形或矩形轮廓、收分、拱顶、切角、足部支撑。影响剪影的形状用几何实现。 |
| 次级构造 | 盖底层次、线脚截面、嵌板、檐口、内凹检修口、独立框架、转角包边。用挤出、旋转体、曲线或适配后的立体模型表达。 |
| 表面细节 | 木纹、织物、铭文、浅刻花与压纹。使用共享纹理、ImageGen 底色及配准高度／法线，保持适当纹理比例。 |

矩形结构本身可以成立，例如量规、校准块和旅行箱。按用途决定精细程度：量规不需要装饰性曲边，舞匣则应保留参考中的台座、边框和支脚。不要给每个物件强加曲线、固定数量的装饰或同一种花纹。

概念图应先解决器形，再解决材料与装饰。已有粗模只约束尺寸、维修空间和活动接口；不要为了少改代码而要求 ImageGen 反复画同一个光滑方盒。某处结构从现有角度看不清时，补需要的侧视或截面说明即可。

概念图里的机械结构也可能画错。器形与已校核的传动、孔轴或维修空间冲突时，保留成立的机构，说明必要的局部造型调整；不要为照搬图片而恢复悬空齿轮。需要时只补受影响的参考视图。

## 建模分工

- **规则但精致的器形**：代码做切角壳体、分层线脚、弧形支架、车木脚、凹板等。按参考轮廓写截面；倒角宽度和段数依据游戏中的尺寸决定，不统一套极小倒角。
- **复杂立体外形**：异形壳体、完整雕塑、立体装饰构件可用 Meshy；拆出活动件，回到 Blender／代码校正接口。不要把一整台需要拆修的机关生成为不可分离雕塑。
- **精密传动和配合面**：齿轮、轴、孔、轨道和限位按参数建模。外壳围绕这些接口塑形，不能用外观模型随意移动传动轴心。
- **浅浮雕**：猫咪牌面、刻花等继续走 ImageGen + 高度／法线；造型精修不意味着把浅浮雕升级成 Meshy 高模。

控制节点、渲染网格和加工面允许分别组织。原有点击与运动接口可以绑定新网格或其父节点；不会因为“要保留旧编号”就只能保留粗糙盒板。修正技术接口时只替换必要区域；若必须重做整个可见零件，也要保留其外形、边缘和材质完成度，避免精修把手重新退化成方块。

## 看模型，不只看生成记录

在可比的视角下查看概念图与模型：

1. 先看没有纹理干扰的剪影或灰模。参考里的切角、收分、层叠边框、支脚是否真实存在，比例是否接近？
2. 再看材质与受光。边缘过硬、平滑法线错误、木纹尺度过大，都会制造积木感；先区分形体问题和着色问题。
3. 最后回到游戏灯光、描边与实际镜头，在 100% 和 200% 下查看。重要造型要看得见，不能只在超近的 Blender 渲染中成立。

玩法通过但形体没有落实时，记录为“可玩粗模／外观待修”。概念图生成、Meshy 局部构件、美术完成、游戏接入分别记录实际产物；不要把“ImageGen 已画过”写成“游戏模型已还原”。这些检查由执行者完成，不自动产生一次新的用户审批。

## 典型修正

- **舞匣只有木方盒和兔子雕像**：对照概念图补台座线脚、转角、支脚、内凹检修口及转台层次；兔子本身已有合适模型时无需重生。
- **精密锁像几根方条摆进盒子**：保留真实锁片、横栓与孔槽，补有用途的导向、螺钉、握持部和壳体边缘；检查这些可见构件也能装配和运动。
- **表面已有漂亮纹理，灰模仍缺少主要形体**：先修轮廓和截面，再调整材质。继续提高贴图分辨率不能补回缺失的体积。

仅要求优化 skill 或审查方案时，更新规则和具体问题记录；不启动未要求的批量重做或付费生成。
