# 机关与分件

在概念图之前读本页。已有结构只需补本轮会改变的部分。

## 规格必须能回答的问题

1. 输入是什么：转钥匙、拉拨杆、压下盖子、上发条？
2. 哪个零件将输入传给下一个零件？驱动件与从动件的轴心、方向及行程是什么？
3. 什么限制运动：止挡、弹簧、锁片、齿数比例、槽口？
4. 故障真实落在哪个部件上？修理改变哪个尺寸、形状或装配状态？
5. 玩家如何看到和触及故障？什么动作证明修好了？

动力路径与维修状态机分别记录。视觉上转齿轮可以使用运动学关系，不必额外建立刚体仿真；不要把假的齿轮咬合包装成真实物理模拟。

含齿轮的机构要检查齿形、模数、中心距、工作平面与相位；轴、轴承和支座应说明力如何传到下一件。用同一输入推导从动转向、速比和连杆位置，并观察完整周期里的接触、穿插和脱离。几个零件分别按时间自转，不能作为已经连接的传动链。

## 坐标与接口

- 根节点位于物件支撑面的指定原点。记录真实尺寸及作者／运行时坐标系；Blender 通常 Z 向上，glTF Y 向上，导出转换只做一次。
- 几何网格挂在固定命名的枢轴下，例如 `ROOT / BODY / LID_PIVOT / LID_PANEL`。生成服务可替换网格，不能控制枢轴权威。
- 接口记录位置、法向、配合尺寸和允许误差；铰链记录轴心、轴向、开合极限。孔洞、滑轨、接榫等配合面由规格生成或修整。
- 每个活动部件有安装变换和取出后的放置变换。拆下后放在托盘／桌面；安装后与原接口一致。
- 做到开、关、损坏、拆出状态都成立；不能只在封闭外壳遮挡时看起来正确。

## 拆分决策

先按运动与维修分件，再按生成质量细分立体外观件。两层分件可以不同：一个铰链盖可由低模木板、带 ImageGen 法线的浅浮雕牌面和代码铜边组合，共用盖子的枢轴。完整立体灯座才考虑 Meshy；表面纹样按 [浅浮雕材质流程](surface-relief.md) 制作。

| 观察到的问题 | 处理 |
| --- | --- |
| 简单长条弯曲、孔距不准 | 换成参数化代码几何，保留原材质 |
| 平面牌上的浅浮雕被做成重型网格 | 将已有形体烘焙到简单载体，或改用 ImageGen 配准材质；不继续付费重生 |
| 立体生成件很好但安装面鼓包 | Blender 修平安装面／校正接口，保留主体体积 |
| 盖与底粘在一起 | 沿真实接缝拆开、补内壁；若无足够可用几何，再分别生成 |
| 多个装饰融合、细柄消失 | 对受影响的部件单独生成，继承整体参考的材质和比例 |
| 远观过密或纹理太大 | 派生 LOD 和缩小贴图，无需重生整件 |

拆分后为每个部件单独准备完整参考图。爆炸图只用于设计解释，不作为一个“物体”提交给 image-to-3d。多个方向的输入应属于同一部件；正面、背面不能各自来自不同设计。

## 粗模验收

先用廉价几何跑一次目标玩法：部件可见 → 拆下 → 操作／选配 → 装回 → 试用。证明控制点没有被外壳遮住、拆件有摆放空间、手动加工有连续区域。材料进度应表现为可见形变或装配变化，不以文字按钮替代修理。

精细外观替换后重新检查受影响的交互。保留原粗模和控制绑定作为调试依据，不能让 Meshy 返回的节点名决定存档中的任务 ID。

粗模通过后，按 [器形还原](visual-fidelity.md) 对照概念图完成外壳及可见构件。接口尺寸是约束，可见轮廓仍可以重建；为保留交互而只给旧方块加贴图，会跳过这一阶段。
