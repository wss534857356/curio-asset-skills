# 浅浮雕用材质，立体体积用几何

为 BOM 决定制作路线时读本页。短曲匣盖内那种贴在平面上的猫咪铜浮雕，默认用 ImageGen + 法线纹理完成，不先生成百万面模型再减面。

## 路线判断

| 观察和用途 | 路线 |
| --- | --- |
| 图案附着于平面或规则曲面，主要通过表面受光表达凹凸 | 低模载体 + ImageGen 配准材质 |
| 有独立的侧面与背面、明显凸出体积、复杂外轮廓或真实镂空 | 代码几何或 Meshy 立体模型 |
| 完整工件形体复杂，如守夜鸦提灯、圆雕摆件、舞匣的小舞者 | Meshy 优先评估；框架、转轴和精密接合面仍按规格制作 |
| 完整工件只是盒、木条、规则金属结构 | 代码建模 + 材质，不因“完整”而强制 Meshy |

装饰画得复杂，不等于需要复杂网格。先在实际观察距离评估轮廓和视差；承载板厚度、倒角、边框与螺钉可以保留少量几何。

## ImageGen 材质流程

1. 建简单载体并确定同一 UV、物理尺寸和有效图案区域。
2. 用 ImageGen 绘制正交、无固定高光和投影的底色图。保持纹样、材质区域与载体边缘配准。
3. 以同一图案为参考，生成专门的浅雕高度稿或切线空间法线图。高度稿明确白色较高、黑色较低，不包含照明；不能直接拿彩色金属图的亮度当高度。
4. 高度稿经已授权的材质工具按实际浅雕深度转换法线，或清理并校验生成的法线。依项目约定检查切线方向、绿色通道与归一化；法线／高度／金属度／粗糙度按数据图读取，底色按颜色图读取。
5. 同一浮雕用金属度和粗糙度区别铜与底材，保留原画源文件与材质制作参数，输出游戏需要的贴图及小型载体 GLB。

对已有浅浮雕网格，可在本地把细节烘焙到简单载体，不额外重生 Meshy 模型。改 skill 不会自动删除或替换已经交付的网格；资产替换按当前任务范围进行。

## 验收与边界

让侧光从左右移动，再看正面、斜面与 200% 检视：猫的脸、身体与花纹应有一致凸起方向，亮暗随灯光变化，轮廓与载体边缘配准，不出现双重阴影。

法线不改变实际剪影、碰撞和真实镂空。若从侧面需要看到明显厚度，或突出部分要被单独拆下，就为这些区域保留必要几何；其余表面细节仍可用法线。通常无需把整块纹样转成重型网格。

Meshy 任务计划仅计算真正需要生成的立体部件。纯贴图路线不预留或消耗模型生成、Remesh、UV API 的积分。
