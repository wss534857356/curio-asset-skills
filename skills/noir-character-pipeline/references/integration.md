# 2.5D 人物接入与调光

本仓库分发工作流、提示词与只读检查器，不附带原游戏的人物素材、shader 或调光网页。接入时复用目标项目的人物配置与材质系统。

## 配置与加载

每个人物登记自己的 albedo、opacity mask、form normal，以及可选 material map；另记录角色 ID、世界尺寸、原点、曝光和法线强度。区分专用法线与回退，健康路径不同时下载首选和备用全套图。

建议文件名为 `npc-<id>-albedo.png`、`npc-<id>-mask.png`、`npc-<id>-normal-form.png`、`npc-<id>-material.png`。已有素材无需仅为统一名字而搬迁。只补贴图时保持角色设定、剧情入口和存档结构。

## 材质约定

- Albedo 使用 sRGB；normal、mask、material 使用线性数据／NoColorSpace。各图的 UV 和 flipY 一致。
- Normal 按 OpenGL +Y 编码。解码并归一化 `2 * RGB - 1`，调强度后再次归一化，再通过实际切线基转入灯光空间。
- 本流程材质示例是 **R=轮廓响应、G=高光权重、B=粗糙度**，并非 ORM；目标 shader 定义不同则先映射。
- 不透明度可由 albedo alpha 与独立 mask 相乘，具体取哪个通道由项目定义。渲染裁切与点击拾取使用一致覆盖。
- 法线可用 mipmaps 抑制远处噪声；不要为平滑法线模糊彩图描线。强度、LOD 与裁切阈值没有全角色通用值。

人物与场景共享世界灯。赛璐璐沿 N·L 分档，保留彩图和灯色；全屏黑白阈值不是同一效果。平面人物的法线受光不等于几何自阴影、皮肤散射或真实转身。

## 调光验收

在目标引擎的工作台提供选角色、固定机位、normal OFF/ON、左右主光、法线可视化、连续／赛璐璐受光，无需依赖特定网页地址。

1. 同一人物只切法线开关，再只改变灯的 X 方向。脸颊、鼻梁、衣褶跟灯移动，五官与轮廓保持配准。
2. 连续与赛璐璐对照使用相同法线与灯光，仅改明暗分档。
3. 核对实际加载路径、回退来源和参数，不凭非零像素差判合格。
4. 在真实出场场景检查入口、遮挡与日夜曝光。工作台正常不代表接入完成。
5. 隔离浏览器或测试场景，保留玩家存档。静止立绘换图不应触发无关阴影重绘。

保存实际提示词、选用图、输入角色、尺寸和版本。独立估计的形体法线不标作三维烘焙法线；机器检查与视觉检查分别记录。
