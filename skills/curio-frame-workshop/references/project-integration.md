# 画框接入目标项目

先定位目标项目的画作登记、模型入口、材质库与预览场景。本技能不依赖原游戏目录或指定网页；生成器输入是 [frame-spec.json](../assets/frame-spec.json) 等规格文件。

- 画芯、背板、框体和徽章独立。导出节点的 part_id、label、explode_direction 可供检视器映射；元数据本身不会实现拆件交互。
- 按实际画芯比例求框尺寸，重算节点与挂点；纹理密度、端面方向和徽章比例保持稳定。
- 相同材质和纹章复用贴图，真假画作通常共用框体。不要将画框画进画芯底色，也不要把画内线索误贴到框上。
- 新版本目录保留 .blend、规格和预览；选用 GLB 与贴图接入资源清单。只替换本次要求的画作，保留旧版对照。
- 复核加载、失败回退、共享资源释放和构建资源清单。开发页面可见不等于发布包已包含资源。

验证两种长宽比、正面与斜视灯光，以及本次需要的隐藏和拆分。模板库不是新增剧情藏品，不自动改库存和存档。
