# 油画接入与状态映射

内置 C01～C10 是示例配方，不包含原项目画芯。准备脚本没有源图时仍会输出待生成任务包；不会调用服务或把缺失画芯标为完成。

## 准备任务

从仓库根运行：

```sh
python skills/curio-oil-paintings/scripts/prepare_painting.py --recipe C01 --out work/rabbit-v1
```

自定义题材从 [配方示例](../assets/painting-recipe.example.json) 修改身份、真伪差异、画幅和名单，使用 `--recipe-file` 传入。`legacy_canvas_relative` 是相对 `--project-root` 的可选参考图路径；文件缺失时任务的 source 为 null，不代表参考已核对。已有 task.json 的输出目录拒绝覆盖，应使用新版本目录。

任务包包含提示词、task.json、surface.json 和 frame.json。目视核对实际画芯后再处理材质。`paint_surface.py` 生成通用笔触、织纹与独立污渍；[法线先行流程](normal-first.md) 的方向场需要任务适配实现，原游戏定制构建器不随仓库分发。

## 登记与渲染

真伪和保存状态独立记录：

| 身份 | 保存状态 | 内容 |
|---|---|---|
| genuine | clean | 真品画芯与基础材质 |
| genuine | oily | 同一真品画芯加独立油膜 |
| forged | clean | 指定差异的赝品画芯与匹配材质 |
| forged | oily | 同一赝品画芯加独立油膜 |

字段名适配目标引擎，只登记实际完成并检查过的状态。保留原始参考、上一版与生成记录，运行图进入项目资源目录，不依赖工具缓存。

画芯用 sRGB，法线与粗糙度作为数据。框体、徽章和画芯分开；画内首饰仍是画面内容。同框型和重复材质共享资源，不为每种污渍状态复制整个模型和整套纹理。

## 清洁边界

附带脚本提供静态材质层生成。清洁玩法需目标游戏实现运行时遮罩、刷子轨迹、线索揭示和保存，并实际操作验证；隐藏一层的截图不能证明这些功能。清洗不把赝品画芯换回真品，补缀也保持独立。
