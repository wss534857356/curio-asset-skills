# 颜料、画布、油污与补缀

```text
python SKILL_DIR/scripts/prepare_painting.py --recipe C01 --project-root PROJECT --out JOB
blender --background --factory-startup --threads 4 --python SKILL_DIR/scripts/paint_surface.py -- --spec JOB/surface.json --out JOB/surface-r01
```

`paint_surface.py` 使用 Blender 配套 NumPy；不需要外部生图凭据。它生成技术材质图，不生成画作或语义赝品。输入高度稿时必须与目标像素宽高一致；不同画幅的稿先显式配准，不静默拉伸。

## 分层

|层|用途|清理行为|
|---|---|---|
|画作底色|真品／赝品描绘内容|不随擦污权重变化|
|颜料高度与法线|厚涂笔触及调色刀起伏|保留；不能由底色亮度推出|
|亚麻织纹|很浅、方向稳定的经纬组织|随画布物理尺寸保持合理密度|
|油渍|局部压暗、透出原画、低粗糙度油膜|用独立 `oil_mask` 和 `clean_amount` 移除|
|补缀|短段连续凸起、边缘脊与不同吸油性|单独 `repair_mask`／高度，不默认被擦污动作抹掉|

脚本的高度幅度是可调美术参数，使用米，不是对真实古画的材料测量。默认颜料约数十到数百微米量级的视觉起伏，补缀更高；目标镜头若看见剪影或摸得到独立缝线，就另外生成少量几何。默认只输出表面模型，不冒充纤维力学或流体模拟。

通用笔触模式生成有方向的短笔触和织纹；`height_guide` 输入可取代通用笔触，使其跟随具体画作。可用 ImageGen 单独制作同构图灰度高度稿，白高黑低、无光照；先目视确认其笔触与画面一致。图像本身的面部高光、衣物白色和阴影不能当厚度。

`normal.png` 从合成后的物理高度求导：U 向右，V 向上，PNG 行自上而下，因此绿色导数符号需要转换。默认 +Y 切线空间；OpenGL／glTF 数据约定必须与目标引擎一致。高度、粗糙度、法线按 Non-Color 读取；底色按 sRGB。输出 ORM 的 R 默认恒 1，代表未烘焙 AO。

`layers/oil/` 输出 RGBA 颜色层、遮罩、薄膜高度和粗糙度；`layers/repair/` 输出连续珠状补痕高度、遮罩及粗糙度。`composite/` 给出当前清洁权重下的高度、法线、粗糙度，原层均保留。颜色叠加用油污 RGBA 在 shader 中与当前画芯合成；真伪底色不能被程序凭空改成另一版本。

同一配对共享织纹、笔触种子和无关区域。新添戒指或人物的位置若有覆绘，另做该区域的局部高度差；不能让两张画因随机全图笔触不同而处处露馅。

至少对照清洁前后和移动掠射光：油膜的反光可随视角变化，补痕是一串局部连贯凸起，污渍移除后仍是同一版本画作。只有把清理遮罩接进运行时并实际操作验证后，才能称动态清洁已实现。
